# Team C_Love-FocusFlow

FocusFlow is a Pomodoro timer and daily focus tracker. Target price: $4.99.

## Features
- Focus / short break / long break timer (long break after every 4 focus sessions)
- Accurate timer (keeps time even if the tab is in the background), tab-title countdown, desktop notifications
- Daily stats: sessions vs. daily goal and focus minutes
- Day streak counter
- 7-day bar chart of sessions
- Custom durations and daily goal
- CSV export of history
- All data stays on your device (localStorage), no account needed

## Run it
No build step. Open `index.html` in any modern browser, or serve the folder:

```
python3 -m http.server 8000
```
then visit http://localhost:8000.
